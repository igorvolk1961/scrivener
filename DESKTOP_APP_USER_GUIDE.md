## Введение

Десктопное приложение Scrivener предназначено для отладки и тестирования системы RAG в автономном режиме без необходимости подключения к реальному файловому хранилищу КФО. Приложение предоставляет графический интерфейс для:

- Взаимодействия с агентом через чат
- Управления документами в векторной базе данных
- Тестирования различных конфигураций LLM и эмбеддингов
- Работы с коллекциями векторной БД

Приложение автоматически запускает встроенный эмулятор КФО, который имитирует файловое хранилище для локальной разработки и тестирования.

## Требования и установка

### Системные требования

- Python 3.8 или выше
- Установленные зависимости из `requirements.txt`
- Запущенный API сервер Scrivener (по умолчанию на `http://localhost:8000`)
- Запущенный Qdrant (для работы с векторной БД, по умолчанию на `http://localhost:6333`)

### Установка

1. Убедитесь, что все зависимости установлены:
```bash
pip install -r requirements.txt
```

2. Убедитесь, что API сервер Scrivener запущен:
```bash
python main.py
# или
uvicorn api.main:app --host 0.0.0.0 --port 8000
```

3. Убедитесь, что Qdrant запущен (если планируете работать с векторной БД).

## Запуск приложения

Запустите десктопное приложение командой:

```bash
python desktop/main.py
```

При первом запуске:
- Автоматически создается директория `data/debug_storage/` для локального хранилища эмулятора КФО
- Автоматически запускается эмулятор КФО на порту 8001
- Открывается главное окно приложения

**Примечание:** При закрытии приложения эмулятор КФО автоматически останавливается.

## Обзор интерфейса

Главное окно приложения содержит:

- **Строка меню вкладок** - переключение между разделами приложения
- **Рабочая область** - содержимое выбранной вкладки
- **Строка статуса** (внизу) - отображение текущего статуса операций

### Вкладки приложения

1. **Чат** - взаимодействие с агентом
2. **RAG управление** - управление документами в векторной БД
3. **Коллекции** - управление коллекциями Qdrant
4. **Настройки** - конфигурация приложения
5. **Пользователь** - управление пользователями эмулятора КФО

## Работа с вкладками

### Вкладка "Чат"

Основной интерфейс для взаимодействия с агентом Scrivener.

#### Левая панель - настройки

**Режимы работы:**
- ☐ **Использовать интернет** - включает веб-поиск через Tavily API
- ☐ **Использовать базу знаний** - включает поиск в векторной БД через RAG

**Информационный объект:**
- **IRV ID** (опционально) - UUID версии информационного объекта для контекста
- **Chat History IRV ID** - UUID версии ИО с историей чата (для сохранения/загрузки истории)

#### Правая панель - чат

- **История диалога** - отображает все сообщения пользователя и ответы ассистента
- **Поле ввода** - для ввода сообщений
- **Кнопки:**
  - **Отправить** - отправляет сообщение агенту
  - **Очистить историю** - очищает историю диалога
  - **Сохранить историю** - сохраняет историю в файл (JSON)

#### Использование

1. Выберите режимы работы (интернет, база знаний)
2. При необходимости укажите IRV ID и Chat History IRV ID
3. Введите сообщение в поле ввода
4. Нажмите "Отправить"
5. Дождитесь ответа ассистента в истории диалога

**Цветовая индикация сообщений:**
- Синий - сообщения пользователя
- Зеленый - ответы ассистента
- Красный - ошибки

### Вкладка "RAG управление"

Управление документами в векторной базе данных. Содержит три подвкладки:

#### Подвкладка "Загрузка в хранилище"

Загрузка файлов в локальное хранилище эмулятора КФО.

**Шаги:**

1. **Создание или указание IRV ID:**
   - Введите существующий IRV ID в поле "IRV ID"
   - Или нажмите "Создать новый" для генерации нового UUID

2. **Выбор файлов:**
   - Нажмите "Выбрать файлы"
   - Выберите файлы (поддерживаются .docx и .txt)
   - Выбранные файлы отобразятся в списке

3. **Управление списком:**
   - "Удалить выбранный" - удаляет выделенный файл из списка
   - "Очистить список" - очищает весь список

4. **Загрузка:**
   - Нажмите "Загрузить в хранилище"
   - Дождитесь завершения операции
   - Результаты отобразятся в нижней панели

**Результаты загрузки:**
- IRV ID созданного/использованного информационного объекта
- Список загруженных файлов

#### Подвкладка "Добавление в RAG"

Индексация документов из хранилища в векторную БД.

**Шаги:**

1. **Указание IRV ID:**
   - Введите IRV ID информационного объекта с загруженными файлами

2. **Загрузка списка файлов:**
   - Нажмите "Загрузить список файлов"
   - Список файлов из хранилища отобразится в средней панели

3. **Добавление в RAG:**
   - Нажмите "Добавить файлы в RAG"
   - Дождитесь завершения индексации
   - Результаты отобразятся в нижней панели

**Процесс индексации:**
- Файлы загружаются из эмулятора КФО
- Обрабатываются через SmartChanker
- Создаются чанки с метаданными
- Чанки индексируются в векторную БД

**Результаты:**
- Информация о количестве обработанных файлов
- Количество созданных чанков
- Детальная информация о каждом файле

#### Подвкладка "Управление RAG"

Управление уже проиндексированными документами.

**Операции:**

1. **Удаление из RAG:**
   - Введите IRV ID
   - Нажмите "Удалить из RAG"
   - Все чанки, связанные с указанным IRV ID, будут удалены

2. **Информация о файле:**
   - Введите IRV ID
   - Нажмите "Информация о файле"
   - Получите детальную информацию:
     - Количество чанков
     - Типы чанков (text, toc, table)
     - Статистика по файлам

### Вкладка "Коллекции"

Управление коллекциями в векторной базе данных Qdrant.

#### Функции

1. **Обновить список** - загружает актуальный список коллекций из Qdrant
2. **Проверить здоровье** - проверяет доступность Qdrant сервера
3. **Удалить коллекцию** - удаляет выбранную коллекцию (требует подтверждения)

#### Таблица коллекций

Отображает информацию о каждой коллекции:
- **Имя** - название коллекции
- **Точек** - количество точек (чанков) в коллекции
- **Статус** - статус коллекции
- **Размер вектора** - размерность векторов

#### Использование

1. Нажмите "Обновить список" для загрузки коллекций
2. Выберите коллекцию в таблице
3. Нажмите "Удалить коллекцию" для удаления (с подтверждением)
4. Результаты операций отображаются в нижней панели

**Внимание:** Удаление коллекции необратимо и удаляет все данные в ней!

### Вкладка "Настройки"

Конфигурация приложения и параметров по умолчанию.

#### Секции настроек

**API настройки:**
- **API URL** - URL API сервера Scrivener (по умолчанию `http://localhost:8000`)
- **CFX Emulator URL** - URL эмулятора КФО (по умолчанию `http://localhost:8001`)

**LLM настройки по умолчанию:**
- **URL** - URL API LLM провайдера
- **API Key** - ключ доступа к LLM API
- **Модель** - название модели LLM (например, `gpt-4o-mini`)
- **Температура** - параметр температуры генерации (0.0 - 2.0)
- **Max Tokens** - максимальное количество токенов в ответе
- **Системный промпт** - системный промпт для LLM (используется только при простом режиме без агентов)

**Embeddings настройки по умолчанию:**
- **API Key** - ключ доступа к API эмбеддингов
- **URL** - URL API эмбеддингов
- **Модель** - название модели эмбеддингов

**Qdrant настройки по умолчанию:**
- **URL** - URL сервера Qdrant (по умолчанию `http://localhost:6333`)

#### Сохранение и загрузка

- **Сохранить настройки** - сохраняет текущие настройки в файл `data/debug_config.json`
- **Загрузить настройки** - загружает настройки из файла

**Примечание:** Настройки автоматически загружаются при запуске приложения.

### Вкладка "Пользователь"

Управление информацией о пользователе эмулятора КФО.

#### Поля

- **ID** - уникальный идентификатор пользователя (обязательное поле)
- **Имя** - имя пользователя
- **Email** - электронная почта
- **Должность** - должность пользователя

#### Операции

- **Загрузить** - загружает информацию о пользователе из хранилища
- **Сохранить** - сохраняет информацию о пользователе в хранилище

**Примечание:** Информация о пользователе автоматически загружается при открытии вкладки.

## Типичные сценарии использования

### Сценарий 1: Индексация документа и поиск информации

1. **Загрузка файла в хранилище:**
   - Откройте вкладку "RAG управление" → "Загрузка в хранилище"
   - Нажмите "Создать новый" для создания IRV ID
   - Нажмите "Выбрать файлы" и выберите документ (.docx или .txt)
   - Нажмите "Загрузить в хранилище"
   - Запомните IRV ID

2. **Индексация в RAG:**
   - Перейдите на подвкладку "Добавление в RAG"
   - Введите IRV ID
   - Нажмите "Загрузить список файлов"
   - Нажмите "Добавить файлы в RAG"
   - Дождитесь завершения индексации

3. **Поиск информации:**
   - Откройте вкладку "Чат"
   - Включите режим "Использовать базу знаний"
   - Введите вопрос о документе
   - Нажмите "Отправить"
   - Получите ответ на основе проиндексированного документа

### Сценарий 2: Работа с историей чата

1. **Создание IRV ID для истории:**
   - В эмуляторе КФО создайте новый IRV ID для хранения истории
   - Или используйте существующий IRV ID

2. **Использование истории:**
   - Откройте вкладку "Чат"
   - Введите Chat History IRV ID в соответствующее поле
   - История будет автоматически загружаться и сохраняться

3. **Сохранение истории:**
   - После диалога нажмите "Сохранить историю"
   - Выберите файл для сохранения (JSON формат)

### Сценарий 3: Комбинированный поиск (RAG + Интернет)

1. **Настройка:**
   - Откройте вкладку "Настройки"
   - Укажите API ключ для веб-поиска (Tavily)
   - Сохраните настройки

2. **Использование:**
   - Откройте вкладку "Чат"
   - Включите оба режима: "Использовать интернет" и "Использовать базу знаний"
   - Введите запрос
   - Агент будет использовать и базу знаний, и веб-поиск

### Сценарий 4: Управление коллекциями

1. **Просмотр коллекций:**
   - Откройте вкладку "Коллекции"
   - Нажмите "Обновить список"
   - Просмотрите информацию о коллекциях

2. **Проверка здоровья Qdrant:**
   - Нажмите "Проверить здоровье"
   - Убедитесь, что Qdrant доступен

3. **Удаление коллекции:**
   - Выберите коллекцию в таблице
   - Нажмите "Удалить коллекцию"
   - Подтвердите удаление

## Решение проблем

### Проблема: Не удается подключиться к API серверу

**Симптомы:**
- Ошибка "Connection refused" или "Соединение отклонено"
- Статус "Ошибка соединения"

**Решение:**
1. Убедитесь, что API сервер Scrivener запущен:
   ```bash
   python main.py
   ```
2. Проверьте URL API в настройках (вкладка "Настройки" → "API URL")
3. Проверьте, что порт 8000 не занят другим приложением

### Проблема: Не удается подключиться к Qdrant

**Симптомы:**
- Ошибка при работе с векторной БД
- Сообщение "Qdrant недоступен"

**Решение:**
1. Убедитесь, что Qdrant запущен:
   ```bash
   docker run -p 6333:6333 qdrant/qdrant
   ```
2. Проверьте URL Qdrant в настройках (вкладка "Настройки" → "Qdrant URL")
3. Проверьте доступность Qdrant через вкладку "Коллекции" → "Проверить здоровье"

### Проблема: Ошибка при индексации документов

**Симптомы:**
- Ошибка "missing_embed_api_key" или "empty_embed_api_key"
- Ошибка при добавлении файлов в RAG

**Решение:**
1. Откройте вкладку "Настройки"
2. Укажите корректный API ключ для эмбеддингов
3. Укажите URL API эмбеддингов
4. Сохраните настройки
5. Повторите попытку индексации

### Проблема: Эмулятор КФО не запускается

**Симптомы:**
- Сообщение "Не удалось запустить эмулятор КФО"
- Порт 8001 занят

**Решение:**
1. Проверьте, не запущен ли другой экземпляр приложения
2. Проверьте, не занят ли порт 8001:
   ```bash
   # Linux/Mac
   lsof -i :8001
   # Windows
   netstat -ano | findstr :8001
   ```
3. Если порт занят, завершите процесс или измените порт в коде

### Проблема: Файлы не загружаются в хранилище

**Симптомы:**
- Ошибка при загрузке файлов
- Файлы не отображаются в списке

**Решение:**
1. Убедитесь, что файлы имеют поддерживаемые форматы (.docx, .txt)
2. Проверьте, что IRV ID указан или создан
3. Проверьте логи в консоли для детальной информации об ошибке
4. Убедитесь, что эмулятор КФО запущен (проверьте строку статуса)

### Проблема: История чата не сохраняется

**Симптомы:**
- История не загружается при следующем запуске
- Ошибка при сохранении истории

**Решение:**
1. Убедитесь, что указан корректный Chat History IRV ID
2. Проверьте, что эмулятор КФО работает
3. Используйте функцию "Сохранить историю" для ручного сохранения в файл

### Проблема: Агент не отвечает или отвечает с ошибкой

**Симптомы:**
- Долгое ожидание ответа
- Ошибка в ответе ассистента

**Решение:**
1. Проверьте настройки LLM (API ключ, URL, модель)
2. Убедитесь, что API ключ действителен
3. Проверьте логи в консоли для детальной информации
4. При использовании базы знаний убедитесь, что документы проиндексированы
5. При использовании интернета проверьте настройки веб-поиска

## Дополнительная информация

### Структура данных

- **IRV ID** - UUID версии информационного объекта
- **IRVF ID** - UUID файла информационного объекта
- **Chat History IRV ID** - UUID версии ИО для хранения истории чата

### Локальное хранилище

Все данные эмулятора КФО хранятся в директории `data/debug_storage/`:
- Метаданные информационных объектов
- Загруженные файлы
- Информация о пользователях
- История чата

### Конфигурация

Настройки приложения сохраняются в файле `data/debug_config.json`:
- URL API серверов
- Настройки LLM по умолчанию
- Настройки эмбеддингов по умолчанию
- Настройки Qdrant по умолчанию

## Поддержка

При возникновении проблем:
1. Проверьте логи в консоли при запуске приложения
2. Проверьте строку статуса внизу окна приложения
3. Убедитесь, что все сервисы запущены и доступны
4. Проверьте настройки в соответствующей вкладке
