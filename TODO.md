## Критичные проблемы

### 1. Проблема с гибридным поиском

**Проблема**: Полнотекстовый поиск в гибридном режиме не возвращает результатов, что снижает эффективность гибридного поиска.

**Описание**:
- В примерах использования полнотекстовый поиск не дает ни одного чанка
- Возможно, есть ошибка в реализации `_text_search` или `_text_search_fallback`
- Необходимо проверить корректность работы полнотекстового поиска Qdrant

**Задачи**:
- [ ] Провести диагностику полнотекстового поиска
- [ ] Проверить корректность индексации текста в Qdrant
- [ ] Проанализировать логи при выполнении полнотекстового поиска
- [ ] Исправить ошибки в реализации полнотекстового поиска
- [ ] Добавить тесты для проверки работы полнотекстового поиска

**Приоритет**: Высокий

## Архитектурные улучшения

### 3. Абстракция эмбеддера от GigaEmbeddings

**Проблема**: Текущая реализация жестко привязана к GigaEmbeddings, что ограничивает гибкость системы.

**Описание**:
- Система использует `GigaEmbedding` напрямую
- Нет абстрактного интерфейса для эмбеддеров
- Это затрудняет использование других эмбеддеров (OpenAI и др.)

**Задачи**:
- [ ] Создать абстрактный интерфейс `EmbeddingInterface` (аналогично `VectorStoreInterface`)
- [ ] Реализовать `GigaEmbeddingAdapter` как реализацию интерфейса
- [ ] Рефакторинг кода для использования абстрактного интерфейса
- [ ] Создать адаптеры для других эмбеддеров (опционально)
- [ ] Обновить документацию

**Приоритет**: Средний

### 4. Переработка системного промпта для комбинированного поиска

**Проблема**: Системный промпт для комбинированного поиска (интернет + база знаний) может быть неоптимальным.

**Описание**:

- Необходимо улучшить логику выбора между интернетом и базой знаний
- Улучшить синтез информации из разных источников

**Задачи**:

- [ ] Протестировать новую версию промпта
- [ ] Сравнить качество ответов до и после изменений

**Приоритет**: Средний

### 5. Внедрение RAGAS для оценки качества RAG системы

**Проблема**: Отсутствует систематическая оценка качества работы RAG системы.

**Описание**:
- RAGAS (Retrieval-Augmented Generation Assessment) - фреймворк для оценки качества RAG систем
- Необходимо внедрить метрики для оценки:
  - Релевантность извлеченного контекста
  - Точность ответов
  - Полнота ответов
  - Верифицируемость ответов

**Задачи**:
- [ ] Изучить RAGAS и его возможности
- [ ] Интегрировать RAGAS в проект
- [ ] Создать набор тестовых данных для оценки
- [ ] Настроить метрики оценки качества
- [ ] Автоматизировать оценку качества (CI/CD)
- [ ] Создать дашборд для мониторинга качества

**Приоритет**: Низкий (но важен для долгосрочного развития)
